# Peggy的旅行地圖口袋名單

這是一個專門為了快速分類與查找 Google 地圖星星（已儲存地點）打造的單頁 Web 應用程式。

## 🌟 核心特色

1. **多維度雙重過濾**：
   - **地區標籤**：基隆、台北、新北、桃園、新竹、台中、台南、高雄、宜蘭... 一鍵切換。
   - **分類標籤**：咖啡廳、小吃、餐廳、景點、甜點、酒吧... 一鍵篩選。
2. **即時全文搜尋**：搜尋欄輸入任何店名、地址、備註或關鍵字，隨打隨濾。
3. **直達 Google Maps**：每張卡片皆有「開啟 Google Maps」按鈕，點擊立刻在新分頁開啟導航與詳細資訊。
4. **Google Takeout 一鍵匯入**：
   - 支援將 Google 匯出的 `Saved Places.json` / `已儲存的地點.json` 或 `.csv` 拖曳上傳。
   - 自動透過店家名稱與地址辨識地區（如基隆、台北、新北）及分類。
5. **本地儲存（Local Storage）**：資料安全存放於您個人瀏覽器，不需架伺服器，資料不外洩，重開網頁依然保留。
6. **支援編輯與手動新增**：可自由調整分類、填寫自訂推薦菜色與備註。

## 🚀 如何使用

### 步驟 1：直接開啟網頁
直接用 Chrome、Edge 或任何瀏覽器開啟：
`C:\Users\ken03\.gemini\antigravity\scratch\google-map-stars-viewer\index.html`

### 步驟 2：匯入您的 Google 星星名單
1. 前往 [Google Takeout (資料匯出)](https://takeout.google.com/)。
2. 點選「取消全選」，往下找到 **「地圖（已儲存的地點）」** 並勾選。
3. 建立匯出作業並下載解壓縮。
4. 在網頁右上角點擊 **「匯入 Google 星星 (Takeout)」**。
5. 將解壓縮出的 `Saved Places.json` 或 `已儲存的地點.json` 拖入視窗中即可！
